## About me

- 🎓 4th-year **Data Science Engineering** student
- 💼 **Full-stack developer** at **Hortensia Agency**, working on web/SaaS products, client projects, and automation
- 🧠 I like problems that need both halves of the job: a clean product on the surface and solid data work underneath
- 🌍 Languages: Arabic · French · English

## What I'm working on

**Kollabo: an influencer × business collaboration marketplace** (agency project)
- Turborepo monorepo with a Next.js 15 web app, an Expo / React Native mobile app, and background workers
- Postgres + Prisma/Kysely, Redis + BullMQ queues, Meilisearch for discovery, Socket.IO for realtime
- Milestone-based escrow payments on Stripe Connect, with idempotent, audit-logged state transitions
- Admin control plane where marketplace rules (regions, verticals, fees) are driven by the database instead of hard-coded
- Full i18n in English, French, and Arabic (RTL)
- Data work on the matching side: creator reliability scoring and search ranking

**Automation.** I build n8n workflows and Python scripts that remove repetitive work for clients.
